Initial Golden Bootstrap ONE-TIME OPERATION

← Automation · Configuration bundles · Probation soaks

Why this exists. Adopts the pre-existing, traditionally configured network as the initial automation baseline. The network was configured before the automation framework existed, so its running configuration cannot honestly be pushed through Change → validation → plan → Partial UAT → UAT → Probation → 7-day soak. This is not UAT and it does not pretend to be. Opening this page contacts no device and changes nothing.
