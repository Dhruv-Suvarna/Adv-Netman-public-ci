What this mode means

{% if is_partial %}

Partial (UAT) runs an ordered PREFIX of the plan and stops at the first failure. Everything applied before that point is preserved — it is never rolled back automatically. The result records exactly what succeeded, where it stopped and what remains unapplied.

{% else %}

Complete is application-level transactional: before the first change the engine proves it can undo every Configlet (exact inverse, verified by read-back). It applies in plan order, stops at the first failure, requires the postcheck to confirm the intended state, and otherwise compensates what THIS run applied, in reverse order. If that cannot be proven the run is refused before any device is touched. A distributed network has no native ACID transaction; this is a verified compensation contract, not a guarantee.

{% endif %}

Changes the RUNNING configuration only; the startup configuration is not written. This is not the later rollback/removal workflow.
