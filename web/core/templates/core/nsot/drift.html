Status vocabulary

  • IN_SYNC — the compared sources agree.
  • DRIFT — the compared sources disagree on at least one field.
  • UNMANAGED — this device/domain is intentionally out of scope for the comparison (e.g. R5/WebServer).
  • UNAVAILABLE — a source needed for the comparison could not be reached right now (not the same as drift).
  • NOT_COMPARABLE — no reliable automated comparison exists yet for this domain.
